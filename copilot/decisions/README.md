# Trade Lib Decisions

Use this directory for durable product and repository decisions that affect Trade Lib implementation, behavior, or conventions. Link each record to its originating issue when one exists.

Use numbered files with the format `NNNN-short-title.md`. Preserve previous decision records when a later decision supersedes them.

Each decision should include:

- Date
- Status
- Scope
- Decision
- Rationale
- Affected files or areas
- Superseded decisions, when applicable
