# Prompt History

Use this directory for significant changes to prompts, agents, and skills.

Name each entry `YYYY-MM-DD-short-topic.md`, using the date and a concise kebab-case topic. If multiple entries share a date, distinguish them with descriptive topic text; do not add a sequence number.

Record the date, affected asset, change, justification, and any compatibility or migration notes. Keep entries concise and link to the relevant decision record when a change is driven by a repository decision.
