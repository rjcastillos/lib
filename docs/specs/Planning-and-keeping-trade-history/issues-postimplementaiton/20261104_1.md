## Resolution

- Extension validation now accepts ascending and descending impulses when Point C is strictly between Points A and B.
- Replaced the helper's `0.764` level with `0.786` for both extensions and retracements.
- Added direction-aware point labels and covered both supplied extension examples in tests.
- Validation: `node --test html/trade-planner-core.test.js`.
- Changed: `html/trade-planner-core.js`, `html/trade-planner-core.test.js`, `html/trade-planner-app.js`, `html/trade-planner.html`, `docs/specs/Planning-and-keeping-trade-history/README.md`, `docs/specs/Planning-and-keeping-trade-history/follow-up-todo/revOct9.md`, and `copilot/decisions/0015-bidirectional-fibonacci-extension.md`.
- Compatibility: Existing ascending extension calculations retain their formula; the helper now computes descending extensions too. Retracements retain their formula but expose `0.786` instead of `0.764`.
