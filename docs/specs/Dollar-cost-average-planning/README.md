# Dollar Average Cost Reduction Planner & Financial Engine

An open-source, zero-dependency, local single-page tool designed to optimize Dollar-Cost Averaging (DCA) and track real-time Yield on Cost (YOC) performance for high-yield dividend assets.

---

## 📖 System Formula Dictionary & Specifications

This document defines the mathematical engine and computational constraints driving the ledger calculations. Use these formulas for documentation or when rebuilding the backend engine in alternative platforms (like Python, Excel, or Google Sheets).

### 1. Tranche Investment Total
* **Description:** Calculates the gross cash deployment required to execute a specific transaction block, accounting for both equity cost and overhead expenses.
* **Mathematical Formula:** 
  \[\text{Investment} = (\text{Quantity} \times \text{Price per Share}) + \text{Commission}\]
* **Local Web Engine (JS/TS):** `const investment = (qty * price) + comm;`
* **Spreadsheet Implementation:** `=(A2 * B2) + C2`

### 2. Price After Commission
* **Description:** Establishes the real cost-basis localized to a specific transaction layer. It shows the net structural break-even point for that tranche alone.
* **Mathematical Formula:** 
  \[\text{Price After Commission} = \frac{\text{Investment}}{\text{Quantity}}\]
* **Local Web Engine (JS/TS):** `const priceAfterComm = qty > 0 ? investment / qty : 0;`
* **Spreadsheet Implementation:** `=D2 / A2`

### 3. Cumulative Running Quantity
* **Description:** Aggregates the absolute volume of asset inventory across all chronological transaction layers up to the current milestone.
* **Mathematical Formula:** 
  \[\text{Cumulative Shares}_n = \sum_{i=1}^{n} \text{Quantity}_i\]
* **Local Web Engine (JS/TS):** `runningShares += qty;`
* **Spreadsheet Implementation:** `=SUM($A$2:A2)`

### 4. Cumulative Running Investment
* **Description:** Tracks the total financial capital deployed across all sequential transaction tranches up to the current row.
* **Mathematical Formula:** 
  \[\text{Cumulative Investment}_n = \sum_{i=1}^{n} \text{Investment}_i\]
* **Local Web Engine (JS/TS):** `runningInvestment += investment;`
* **Spreadsheet Implementation:** `=SUM($D$2:D2)`

### 5. Dollar Average (Weighted Cost Basis)
* **Description:** Computes the dynamic rolling average cost of the total position. It normalizes distinct entry tiers into a singular structural value benchmark, preventing the distortion that happens when simply averaging share prices directly.
* **Mathematical Formula:** 
  \[\text{Dollar Average}_n = \frac{\text{Cumulative Investment}_n}{\text{Cumulative Running Quantity}_n}\]
* **Local Web Engine (JS/TS):** `const currentAvg = runningShares > 0 ? runningInvestment / runningShares : 0;`
* **Spreadsheet Implementation:** `=SUM($D$2:D2) / SUM($A$2:A2)`

### 6. Annualized Dividend Rate
* **Description:** Projects the fixed forward income metric generated by a single unit of stock across a 12-month fiscal timeline.
* **Mathematical Formula:** 
  \[\text{Annual Dividend Rate} = \text{Monthly Dividend Per Share} \times 12\]
* **Local Web Engine (JS/TS):** `const annualDiv = monthlyDiv * 12;`
* **Spreadsheet Implementation:** `=B1 * 12` *(Assuming monthly dividend is in cell B1)*

### 7. Payable Amount (Per Payout Period)
* **Description:** Calculates the gross dividend income stream generated by the aggregated asset volume accumulated up to the current tier row during a single distribution payout milestone.
* **Mathematical Formula:** 
  \[\text{Payable Amount}_n = \text{Cumulative Running Quantity}_n \times \text{Dividend Payout Rate}\]
* **Local Web Engine (JS/TS):** `const currentPayable = runningShares * divValue;`
* **Spreadsheet Implementation:** `=SUM($A$2:A2) * $D$1` *(Where D1 is the fixed Dividend Payout Rate)*

### 8. Yield on Cost (YOC)
* **Description:** Tracks your actual income yield relative to the personal capital you deployed to acquire the asset. As you successfully lower your Dollar Average via cost reduction tranches, your true Yield on Cost expands independently of public market pricing volatility.
* **Mathematical Formula:** 
  \[\text{Yield on Cost (YOC)} = \frac{\text{Annual Dividend Rate}}{\text{Dollar Average}} \times 100\]
* **Local Web Engine (JS/TS):** `const currentYoc = currentAvg > 0 ? (annualDiv / currentAvg) * 100 : 0;`
* **Spreadsheet Implementation:** `=( $B$1 * 12 ) / F2` *(Where F2 is the Dollar Average of the row)*

## ⚠️ System Validation Constraints & Boundary Rules

1. **Division by Zero Protection:** All calculations executing a division step (such as *Price After Commission*, *Dollar Average*, and *Yield on Cost*) must be bound inside conditional logic check parameters (`quantity > 0` or `runningShares > 0`) to prevent computational application crashes on empty ledger inputs or future empty template rows.
2. **Precision Constraints:** Currency totals must preserve traditional mathematical double-precision float metrics internally during calculating operations, then parse out using fixed string formatting adjustments (`.toFixed(2)`) strictly during the interface rendering phase.
3. **Active Row Filtering Constraint:** The `Cumulative Running Quantity`, `Cumulative Running Investment`, and `Payable Amount` loops must dynamically skip over any row layout tier where the `Active?` checkbox component state evaluates to `false`.
