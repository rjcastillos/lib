## Bullish candle calculations

A bullish candle requires:

C > O

### direction = 'bullish'

### Range     = H - L
### Body      = C - O
### UpperWick = H - C
### LowerWick = O - L

### Proportions of the candle
#### BodyRatio      = Body      / Range
#### UpperWickRatio = UpperWick / Range
#### LowerWickRatio = LowerWick / Range

### Position of the close
#### CloseLocation = (C - L) / Range

### Price-relative movement

#### ReferencePrice = O (Open) 
#### BodyPercent    = Body  / ReferencePrice * 100
#### RangePercent   = Range / ReferencePrice * 100


### ATR 
#### Candle ATR(9)
##### Algorithm

1. Calculate True Range for every candle.
2. Calculate the average of the first 9 True Range values.
3. Store this result as the first ATR value.
4. Apply Wilder's smoothing to all subsequent periods.
5. Return ATR values aligned with the source data index.

---

##### Worked Example ATR(3)

Input:

| High | Low | Close |
|------|------|------|
| 105 | 100 | 102 |
| 108 | 103 | 107 |
| 110 | 106 | 109 |

True Range values:

```text
TR1 = 105 - 100 = 5

TR2 = max(
108 - 103,
|108 - 102|,
|103 - 102|
)
= max(5, 6, 1)
= 6

TR3 = max(
110 - 106,
|110 - 107|,
|106 - 107|
)
= max(4, 3, 1)
= 4
```

For period = 3:

```text
ATR = (5 + 6 + 4) / 3
ATR = 5
```

# RVOL 
## Method A: Standard Daily RVOL

The fundamental calculation formula is straightforward:
\(\text{RVOL}=\frac{\text{Current\ Period\ Volume}}{\text{Average\ Volume\ Over\ }N\text{\ Periods}}\)

Step-by-Step Example: 9 Past Periods + Current Period

Lookback window is \(N = 9\) periods. Here is exactly how to calculate it:

Step 1: sample data 

• Past 9 Periods Volume: 12,000, 15,000, 11,000, 14,000, 16,000, 13,000, 15,000, 17,000, 14,000 shares

• Current Period Volume: 28,000 shares

Step 2: Calculate the historical average

Add the volumes of your 9 historical periods together and divide by 9:
\(\text{Sum}=12,000+15,000+11,000+14,000+16,000+13,000+15,000+17,000+14,000=127,000\)
\(\text{Average\ Volume}=\frac{127,000}{9}\approx \mathbf{14,111.11}\text{\ shares}\)

Step 3: Compute the RVOL ratio

Divide the current period's volume by that historical average:
\(\text{RVOL}=\frac{28,000}{14,111.11}\approx \mathbf{1.98}\)

## Pattern Pseudo code

```text
FUNCTION classifyRelationship(
    prevHigh,
    prevLow,
    currHigh,
    currLow
)

    //--------------------------------------------------
    // HIGH RELATION
    //--------------------------------------------------

    IF currHigh > prevHigh THEN
        highRelation = "HH"
    ELSE IF currHigh < prevHigh THEN
        highRelation = "LH"
    ELSE
        highRelation = "EH"
    END IF

    //--------------------------------------------------
    // LOW RELATION
    //--------------------------------------------------

    IF currLow > prevLow THEN
        lowRelation = "HL"
    ELSE IF currLow < prevLow THEN
        lowRelation = "LL"
    ELSE
        lowRelation = "EL"
    END IF

    //--------------------------------------------------
    // PATTERN CODE
    //--------------------------------------------------

    patternCode =
        highRelation + "-" + lowRelation

    //--------------------------------------------------
    // BUSINESS CLASSIFICATION
    //--------------------------------------------------

    SWITCH patternCode

        CASE "HH-HL":
            return (
                code="HH-HL",
                name="Up Trend Bar",
                category="Trend Continuation"
            )

        CASE "HH-LL":
            return (
                code="HH-LL",
                name="Outside Bar",
                category="Expansion"
            )

        CASE "HH-EL":
            return (
                code="HH-EL",
                name="Bullish Rejection / Expansion",
                category="Expansion"
            )

        CASE "LH-LL":
            return (
                code="LH-LL",
                name="Down Trend Bar",
                category="Trend Continuation"
            )

        CASE "LH-HL":
            return (
                code="LH-HL",
                name="Inside Bar",
                category="Contraction"
            )

        CASE "LH-EL":
            return (
                code="LH-EL",
                name="Descending Base Bar",
                category="Consolidation"
            )

        CASE "EH-HL":
            return (
                code="EH-HL",
                name="Ascending Base Bar",
                category="Consolidation"
            )

        CASE "EH-LL":
            return (
                code="EH-LL",
                name="Bearish Fakeout",
                category="Failure Pattern"
            )

        CASE "EH-EL":
            return (
                code="EH-EL",
                name="Double Bar / Matchbook",
                category="Balance"
            )

        CASE "EL-LH":
            return (
                code="EL-LH",
                name="Descending Triangle Bar",
                category="Consolidation"
            )

        CASE "EL-HH":
            return (
                code="EL-HH",
                name="Bullish Fakeout",
                category="Failure Pattern"
            )

        CASE "EL-EH":
            return (
                code="EL-EH",
                name="Perfect Double Top/Bottom",
                category="Balance"
            )

        DEFAULT:
            return (
                code="UNKNOWN",
                name="UNKNOWN",
                category="UNKNOWN"
            )

    END SWITCH

END FUNCTION
```
