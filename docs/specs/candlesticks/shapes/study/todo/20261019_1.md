- # RVOL 
## Method A: Standard Daily RVOL
For this study the  method compares the total volume of the current day against a simple moving average of total daily volumes over a lookback period (9).

- ATR for this study is confirmed that the loopback is customized to 9 periods against the current one.
Note that for some calculations like the ones to normalize price against recent volatility the ATR value used is not the one in current period but the last period instead for example `BodyATR = Body/ATR(t-1)` but both t and t-1 are calculated using the same method.
